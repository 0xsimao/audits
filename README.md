# Audits

Every security review published under this name. The reports are kept
here, a folder per firm; Sherlock and Code4rena ran both kinds of work
so theirs are split into `private-audits/` and `contests/`.

A review with no report is still listed. Some are private at the
client's request, and some are competitions whose judging the platform
never published — leaving them out would describe a smaller record
than the real one.
