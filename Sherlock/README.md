# Sherlock

The private reviews are reports as Sherlock published them.

A competition's report is the README of its judging repository —
one '# Issue H-1:' block per finding, naming who found it — and
that is what `contests/` holds. The codebase each was performed on
is under `../audit-codebases/`.
